Study Planner Site Plan

Site Name

Study Planner - This name was chosen because it clearly communicates the purpose of the site: helping students organize and track their study tasks. It is simple, memorable, and directly tied to productivity.

Site Purpose

The site provides a digital tool for students to manage their study schedules. It allows users to add tasks, view deadlines in a calendar, and track progress toward completion. The purpose is to improve time management and academic performance.

Scenarios

  • How can I see all my upcoming assignments and deadlines in one place?
  • Can I track how many tasks I've completed versus pending?
  • Is there a way to organize tasks by category (reading, assignments, exam prep)?
  • Can I edit or delete a task if my schedule changes?
  • Does the planner save my tasks so I don't lose them when I close the browser?
  • Can I view my progress as a percentage or with a visual bar?
  • Is there a quick way to see today's tasks only?
  • Can I use the planner on my phone as well as my laptop?
  • Will the planner remind me of upcoming deadlines?
  • Can I share my progress or tasks with a study group?

Color Scheme

Two main colors will be used:

  • Blue (#004080) - Used for headings, navigation bar, and accents to convey trust and focus.
  • Green (#4CAF50) - Used for progress indicators and buttons to symbolize growth and success.

Typography

Fonts selected:

  • Roboto - Used for body text for readability.
  • Montserrat - Used for headings to provide a modern, bold look.

This document uses these fonts to demonstrate the chosen typography.

Wireframe

The wireframe outlines the planned layout for the home page:

Mobile View

  • Hamburger menu with vertical navigation
  • Hero section with welcome text and button
  • Stacked content: description + quick links
  • Footer with attribution

Desktop View

  • Horizontal navigation bar
  • Wide hero banner with call-to-action
